# 🏓 Ping Pong

A small Ping Pong (Pong) game built with plain HTML, CSS and JavaScript. No frameworks, no build step, no dependencies.

## Features

- 1 Player mode (vs CPU) and 2 Players mode
- Ball speeds up with every paddle hit
- Ball angle changes based on where it hits the paddle
- First to 7 points wins
- Pause / resume
- Keyboard, mouse and touch controls
- Responsive layout

## How to Run

1. Download or clone this repo
2. Open `index.html` in any browser

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>/ping-pong
```

- On mobile in 2 Players mode, touch the left half of the screen for Player 1 and the right half for Player 2
